# claude-skills

Skills pessoais do Claude Code. Ficam em `.claude/skills/` e carregam sozinhas em qualquer sessão aberta com este repositório.

| Skill | Para quê |
|---|---|
| `human-motion-design` | Motion de marca feito em código: storyboard, animação 16:9/9:16, MP4 com prévia. Depois de clonar: `npm ci` dentro da pasta. |
| `human-team` | Squad criativa (OpenSquad): brief, conceito, roteiro, arte, storyboard, anúncios, copy e calendário. |
| `production-map` | Playbook de filme generativo: roteiro → bíblia visual → decupagem → prompts com continuidade. |

Para usar em outro projeto, copie a pasta da skill para `~/.claude/skills/` ou para o `.claude/skills/` do projeto.
